### 8. Full Description:
```text
MyRecon is an open-source OSINT toolkit and web application built for authorized digital footprint audits, username enumeration across 500+ platforms, and breach exposure checks.

Unlike traditional username search tools that mistake Cloudflare blocks, sign-in walls, or HTTP 200 error pages for verified user profiles, MyRecon implements a strict 3-state verdict engine (`found`, `not_found`, `unknown`). An inconclusive check remains inconclusive, saving investigators from chasing ghost accounts.

Key Features:
- Evidence-Based Username Sweeps: Checks 500+ standard platforms and 3,000+ extended platforms.
- Credential & Breach Intelligence: Public breach checks without uploading private passwords.
- Keyless Public Data Breach API: Free daily breach metadata feed at /data/v1/ (CC BY 4.0 via HIBP).
- Infrastructure Recon: WHOIS, RDAP, DNS records, and IP geolocation.
- Offline Verdict Demo: Run synthetic tests locally with zero network calls.
- Interactive OSINT Cheat Sheet: Live Google Dork builder for advanced handle and document hunting.
- Multiple Interfaces: Modern responsive web app with streaming NDJSON, scriptable Python CLI, and Flask REST API.
```
