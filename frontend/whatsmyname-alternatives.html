WhatsMyName was archived on 9 November 2026: what to use now

Short answer

WhatsMyName, the username dataset behind many OSINT tools, was archived on 9 November 2026 and is no longer maintained. Its final list of 691 sites stays downloadable under CC BY-SA 4.0, and the whatsmyname.app web search still loaded on 15 November 2026, but nobody is updating the site checks, so results will drift. Maintained alternatives include Sherlock, Maigret and browser tools such as MyRecon.

Checked 15 November 2026 against the project's own repository and web interface. MyRecon is one of the alternatives named and publishes this page.

For eleven years WhatsMyName was the reference list for username searches. It records, for each website, what a page looks like when an account exists and when it does not. Many search tools are built on top of that list, so its closure matters even to people who never used it directly.

What happened to WhatsMyName

On 9 November 2026 the maintainer, Micah Hoffman, archived the WhatsMyName repository and made it read-only. Issues, pull requests and discussions are closed. The project's README gives three reasons: his interests have moved to other projects, keeping hundreds of site detections working had become more than a few volunteers could sustain, and he considers the 2015 problem it was built for to be solved by newer tools.

The README also warns, in its own words, that results should be treated "as leads to verify, not as fact". That advice applies to every username tool, but it matters more now that the list is frozen.

Nothing switches off on a particular day. The decline is gradual: each time a site redesigns a profile page, renames a URL pattern or adds a login wall, its frozen check starts giving wrong answers.

Why a frozen site list gets less accurate

A username check is only as good as its rule for telling a real profile from an empty one. Websites change those signals all the time. When we tested 24 platforms on 6 September 2026, six of them returned the same response for a real handle and an invented one, five of them byte-for-byte identical. A tool that cannot tell those two apart will report accounts that do not exist. The full measurement explains the method.

A maintained list catches those changes and fixes the rule. A frozen list keeps the old rule, so its false positives and missed accounts grow over time. If you rely on results for anything that matters, record which dataset version produced them.

How to move an existing workflow off WhatsMyName

  1. Pin the final dataset. Save a copy of wmn-data.json dated 9 November 2026 with your case files, so old results can be reproduced and explained.
  2. Run a control check. Search a handle you know exists and one you have confirmed does not, in both the old setup and the new tool. Differences show you which frozen checks have already drifted.
  3. Re-check what matters. For open cases, re-run important usernames in a maintained tool and open every profile link by hand.
  4. Log the tool and version. Use the evidence log template to record which tool, version and date produced each finding.

Frequently asked questions

Is WhatsMyName shut down?

The project was archived on 9 November 2026 and is no longer maintained. Its dataset is still downloadable and the whatsmyname.app web search still loaded on 15 November 2026, but no one is updating the site checks.

Can I still use WhatsMyName?

Yes, but treat results with more caution over time. The final 691-site list is frozen, so checks break as websites change. Verify every result by opening the profile yourself.

What is the best alternative to WhatsMyName?

For command-line work, Sherlock and Maigret are maintained and free under the MIT licence. For a browser tool with no installation, MyRecon checks 500+ platforms on a free account. The best choice depends on whether you need local control, reports or convenience.

Is the WhatsMyName data still free to use?

Yes. The dataset is licensed under Creative Commons Attribution-ShareAlike 4.0, so you can keep using and sharing it as long as you give attribution and share changes under the same licence.

Does the shutdown affect other tools?

Any tool that loads the WhatsMyName list inherits the frozen checks. Blackbird's README, for example, says it is fully integrated with WhatsMyName. Check each tool's documentation for whether it maintains its own copy.
