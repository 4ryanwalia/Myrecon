Username discovery: browser or local command line

MyRecon offers a browser username workflow with free guest previews, five signed-in standard scans per day across 560+ platforms, and optional paid Extended packs. Sherlock and Maigret run locally from open-source repositories, while WhatsMyName was archived on 9 November 2026.

Prefer a local CLI when scripted integration and local output control matter, or browser access when installation is impractical. Both workflows require opening original sources and keeping unavailable checks separate.

Breach exposure is a different question

Have I Been Pwned documents searches against its breach dataset. A breach entry can indicate exposure in that dataset; it does not prove that an account remains active, identify every service using an address or establish that a current password is compromised. A public username sweep cannot substitute for breach review. Choose the input and result type you need first, then follow the data source's response guidance.

Specialist tools and data providers

Graph tools, business-data APIs, and search aggregators have different inputs, data rights, and subscription terms, so do not assume they work like a username checker.

Check what each returned relationship actually means and whether it fits your authorized purpose. This hub does not claim to have tested every commercial provider; review official documentation and terms before purchasing or sharing identifiers.

A reproducible comparison sheet

Use an account or identifier you control and record the version, date, input, scan scope, positive and negative controls, returned URLs, unavailable checks, and manually verified outcomes.

Separate setup effort from request duration. An HTTP 200 status is not proof of a profile, a random string is not a verified negative control, and blocked checks belong in the denominator as unavailable.

Worked decision and published limits

Illustrative task: find and close your own old accounts from two remembered usernames. A browser sweep plus saved signup emails is usually enough without the setup overhead of a graph platform, while repeatable local exports favor a CLI.
