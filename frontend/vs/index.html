How we keep this fair

  • We concede where we lose. Every comparison page has a section on where the other tool is better, and it is not a short one.
  • No prices, no screenshots of rivals. Both go stale fast. Features are taken from each project's own README or documentation and dated.
  • Site counts are not results. A bigger list is not more accounts found. When we tested 1,015 sites from Maigret's catalogue, 66 answered 200 OK to a handle that cannot exist. The Maigret page has the full numbers.
  • Test it yourself. Our six tests work on any of these tools, including ours. For the category view, without brand names, read how MyRecon compares.

Spotted something out of date about another project? Tell us and we will correct it.
