MyRecon vs Maigret: browser speed vs CLI dossier depth

Maigret is one of the most capable open-source dossier generators in OSINT, expanding far beyond Sherlock with socid-extractor profile parsing and recursive pivots. MyRecon takes a lighter browser and Android approach designed for fast handle verification without Python dependencies. Here is how they differ in November 2026.

In MyRecon's 1 November 2026 35-control benchmark across 8 platforms, MyRecon (9491be66) and Maigret (0.6.6) both recorded 6 true positives, 0 false positives, 0 false negatives, 18 true negatives, and 11 unresolved checks (24/35 scored = 68.57%).

MyRecon may suit you when

  • No Python environment, Docker image, or CLI flags needed to run sweeps
  • Combines handle discovery with email breach, k-anonymity password, and DNS tools
  • Android app runs checks over handset connectivity to bypass datacenter blocks

Consider the trade-offs

  • Lacks Maigret's native PDF/XMind dossier exports and recursive socid-extractor engine
  • No built-in Tor or I2P proxy routing inside the hosted web interface

Keep Maigret in your terminal toolkit for deep offline reports and Tor-routed scripting; pair it with MyRecon when you want instant browser checks, mobile runs, or quick breach and domain lookups.

Setup model and runtime environment

Maigret runs inside Python 3 (via pip, pipx, or Docker) and also offers a local Flask web interface, Tor, and I2P routing for analysts managing their own proxy egress. MyRecon launches immediately in any desktop browser or via the Android app (com.Myrecon.osint) with zero terminal setup.

Catalogue scope versus recursive dossier parsing

Maigret ships rules for roughly 5,900 sites (checking the top 500 by default) and uses socid-extractor to pull linked aliases, bios, and metadata into recursive passes. MyRecon checks 100 Guest Quick or 560+ Free Standard sites (plus 3,000+ Extended on paid packs) with explicit found, not_found, and unknown labels.

1 November 2026 controlled test results

In our pinned 1 November 2026 study across 35 controls on eight platforms, both MyRecon (9491be66) and Maigret (0.6.6) scored 24 of 35 controls cleanly: 6 true positives, 0 false positives, 0 false negatives, 18 true negatives, and 11 unresolved checks. Maigret left two npm native claims unresolved at HTTP 401.

Exports, team workflows and practical limits

Investigators assembling offline case binders often prefer Maigret because a single --pdf or --html flag compiles a visual dossier with graph relationships. Conversely, people auditing their own footprint on mobile or checking email breaches and DNS records alongside handles get faster triage inside MyRecon.

Frequently asked questions

Does Maigret have more sites than MyRecon?

Maigret lists roughly 5,900 supported sites and checks the top 500 by default, whereas MyRecon checks 100 Guest Quick, 560+ Free Standard, and 3,000+ Extended sites. Raw list size alone does not guarantee every site responds without blocking.

When should I run Maigret instead of MyRecon?

Choose Maigret when you need local-only execution, Tor or SOCKS proxy routing, recursive socid-extractor pivots, or formatted HTML, PDF, and XMind dossier files for offline case storage.

Why does MyRecon perform better on mobile connections for some social sites?

Running MyRecon on Android uses your handset network rather than a datacenter IP, avoiding many automated cloud-range blocks while keeping Python installation unnecessary.

Did Maigret or MyRecon produce false positives in the 35-control test?

Neither tool produced false positives across the 35 controls tested on 1 November 2026. Both achieved 6 true positives, 18 true negatives, and 11 unresolved checks.
