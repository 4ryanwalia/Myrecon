Twenty-three thousand websites. That number is the whole story, because almost none of them are sites you would remember using. The forum you joined once in 2013, the shop that sold one thing you needed, the local club, the game that shut down — small sites with small security budgets, breached individually and unremarkably, then swept into one collection.

Nobody notified anyone. Most of those sites never knew, and a good number no longer existed by the time the collection was published. There is no company here to be accountable, no disclosure statement, and no reset email coming.

The compilation also carried cracked plain-text passwords alongside the hashes, which removes the last bit of friction. If you find yourself in this one, the question is not which site leaked it — that is usually unanswerable — but where else that password was ever used. That is the only question this data makes it possible to act on.
