Choose a free OSINT tool for the question you need to answer. A username check finds candidate public profiles. A breach lookup reports known exposure for an email address. A domain lookup shows published records, and a metadata reader examines a file you already have. Each result needs a different kind of verification.

Username and social media search

Start with a handle you use or are authorized to review. Open promising results at the source to compare the actual username with your records. The same handle can belong to different people.

MyRecon in the browser

Guest Quick searches cover 100 supported platforms and show up to five result cards. A free account includes five Standard username searches a day across a catalogue of 560+ platforms. Blocks, rate limits and ambiguous responses can leave a result unknown. The username checker guide explains how to review the result at the original source.

Sherlock and Maigret on your computer

Sherlock searches supported sites for a username. Maigret also produces reports and can extract public profile details when its site parser supports them. Both are open source and run locally, with requests still going to the sites being checked. Their catalogues and rules differ. The three-tool comparison shows the practical differences.

What the same check can miss

In 600 repeated observations of the same ten handles per platform, a rule based only on HTTP status gave no verdict for six GitHub observations, 120 GitLab observations and all 200 Hacker News observations. It also contradicted the API reference in 20 GitLab observations from repeated checks of one fixture. Platform behavior changed how much the check could tell us. Review the dates, CSV and measurement limits before applying those findings to a different search.

Email and password breach checks

Have I Been Pwned offers a public email breach lookup. Its API requires authorization for email and domain searches. The separate Pwned Passwords range lookup is free and lets clients send a short hash prefix while checking the returned suffixes locally. A breach record can prompt a security review, and a clean result only describes the data checked. The breach checker comparison explains how to interpret both outcomes.

Registration and DNS for a domain you manage

Use ICANN Lookup for published registration information and a DNS lookup for the records a domain publishes. Compare the displayed value with your provider's dashboard and account documentation. DNS over HTTPS protects the connection to the resolver. Authenticating the underlying DNS data requires a separate check such as DNSSEC validation. Public registration may omit contact details.

Image search and file metadata

Google Lens can find similar images or pages where an image appears. Compare dates, attribution and edits at those sources before drawing a conclusion. Use ExifTool locally to see which tags are actually present in a file you own. Missing or edited tags leave gaps, so record the fields you observed and keep the original unchanged.
