Sherlock and Maigret on your computer

Sherlock searches supported sites for a username. Maigret also produces reports and can extract public profile details when its site parser supports them. Both are open source and run locally, with requests still going to the sites being checked. Their catalogues and rules differ. The three-tool comparison shows the practical differences.

What the same check can miss

In 600 repeated observations of the same ten handles per platform, a rule based only on HTTP status gave no verdict for six GitHub observations, 120 GitLab observations and all 200 Hacker News observations. It also contradicted the API reference in 20 GitLab observations from repeated checks of one fixture. Platform behavior changed how much the check could tell us. Review the dates, CSV and measurement limits before applying those findings to a different search.

Email and password breach checks

Have I Been Pwned provides a free public email breach lookup and a free Pwned Passwords range lookup that sends only a short hash prefix while checking suffixes locally.

Its automated API requires authorization for email and domain queries. Treat any breach entry as historical exposure that prompts a security review, and remember a clean lookup only describes the datasets checked. See the breach checker comparison for both outcomes.

Registration and DNS for a domain you manage

Use ICANN Lookup for published registration information and a DNS lookup for the records a domain publishes. Compare the displayed value with your provider's dashboard and account documentation. DNS over HTTPS protects the connection to the resolver. Authenticating the underlying DNS data requires a separate check such as DNSSEC validation. Public registration may omit contact details.

Image search and file metadata

Google Lens can find similar images or pages where an image appears. Compare dates, attribution and edits at those sources before drawing a conclusion. Use ExifTool locally to see which tags are actually present in a file you own. Missing or edited tags leave gaps, so record the fields you observed and keep the original unchanged.

What changed in the best OSINT tools stack

Three shifts separate the best OSINT tools today from older directories: active control probes replacing frozen handle lists, combined breach-plus-registration email triage, and local offline document forensics.

Frequently asked questions

What are the best free OSINT tools to start with?

Pair MyRecon in the browser or on Android for quick handle and reverse email lookups, Sherlock or Maigret for local CLI username sweeps, Have I Been Pwned for breach and Pwned Passwords range checks, ICANN Lookup for domain registration, Google Lens for reverse images, and ExifTool for offline file metadata inspection.

Why do OSINT tool lists disagree on accuracy?

Modern platforms increasingly return HTTP 200 soft-404 pages, JavaScript login shells, and datacenter rate limits. Tools that report only raw site counts inflate false positives compared with control-verified engines that separate found, not_found, and unknown responses.

Can I run a free OSINT investigation without installing Python or Linux?

Yes. Browser workspaces such as MyRecon, Have I Been Pwned, and ICANN Lookup handle username searches, email breach lookups, password k-anonymity checks, and DNS or RDAP inspection directly in a web browser, while local Python CLI scripts remain optional for offline automation.
