Is MyRecon legit? Six checks you can review

Written and reviewed by Aryan Walia (CEH, Founder) · Editorial method · Checked 28 November 2026

MyRecon is the public-source OSINT and privacy toolkit at myrecon.xyz, with an Android app on Google Play (package com.Myrecon.osint). The source code of the web toolkit, CLI and API is published in the public GitHub repository (checked 28 November 2026). It is operated by Aryan Walia in Gurugram, India, and is not connected to other businesses or domains that use a similar name. Often searched as My Recon, myrekon, or myreocn, the official toolkit lives solely at myrecon.xyz.

Evaluate a public-source tool by its result evidence, access limits, data handling and current offer. MyRecon produces candidates for source review; it cannot certify that two accounts belong to one person or that no information exists online.

1. Check the source behind a result

Open a reported profile URL and confirm it resolves to the expected account page. A login form, platform home page or generic application shell is not proof of an account. Under RFC 9110 (HTTP Semantics), HTTP 200 only confirms a page loaded, not that a user exists.

If the source is unavailable, retain that limitation. The false-positive guide explains controls and ambiguous responses.

2. Use verified positive and negative controls

Compare a public account you control with a handle verified missing at the original service. A random-looking string can still belong to someone, so do not call it a guaranteed negative. Record the observation date and check found, not found and unknown separately.

One false result is a detector problem to investigate; it does not establish that every historical result was false. You can inspect MyRecon's own scheduled control runs in the daily public-controls benchmark and our controlled username search study, where each check is graded against official APIs such as the GitHub Users REST API (checked 28 November 2026).

3. Read coverage as attempted scope

The standard release catalogue covers 560+ platforms, and guest Quick scans cover 100 platforms. That figure is attempted scope, not a guarantee that every service answers cleanly on every run. Login walls, rate limits and layout changes can leave a check unknown. Extended uses a separate 3,000+ catalogue.

Discord username vs Discord ID distinction: MyRecon has no direct Discord username sweep because Discord does not publish open web profile URLs for handles. Instead, MyRecon offers a separate Discord ID lookup that decodes numeric Snowflake timestamps locally in your browser and fetches public user fields (username, display name, avatar, banner and public badges) through Discord's documented Get User API endpoint (checked 28 November 2026). Neither tool unlocks private profiles or private servers.

4. Verify the current price and availability

Guests receive a limited Quick username preview (100 platforms, up to 5 result cards shown in full, 5 daily scans), and signed-in free accounts get five complete Standard scans per UTC day across 560+ platforms. Free reverse email and password checks require no sign-in.

Pro is a monthly or yearly subscription via PayPal (USD) or Razorpay (INR) with a 7-day free trial, renewing until cancelled. A separate one-time purchase gives Extended credits with no renewal. Because prices change with promotions, read current plans and checkout details and our refund and cancellation policy before paying. The Android app is available globally on Google Play; Deep Search unlock requirements are shown in the app.

5. Review actual data handling

MyRecon does not save search inputs, scan results or lookup history in Firebase or server storage for any access tier. Active worker buffers exist in temporary memory only while running and delivering a scan, and are removed after delivery or within 60 seconds if undelivered.

Browser-local sessions, exports, hosting logs, analytics and third-party source requests are separate data flows documented in the privacy policy.

Do not assume any online tool is invisible because a guest preview needs no account: upstream public websites and hosting providers (Vercel and Render) still process standard network requests and short-term access logs. Only search identifiers you own or are authorized to review.

What MyRecon does and does not do

Legitimate OSINT tools state their boundaries plainly. MyRecon inspects publicly reachable web endpoints and documented public breach catalogues; it is not a people-search data broker or a private surveillance tool.

  • What MyRecon does: checks public profile pages across 560+ Standard or 3,000+ Extended platforms, labels blocked or ambiguous responses as unknown, checks emails against LeakCheck and XposedOrNot plus optional Holehe registration signals, hashes passwords locally with k-anonymity, decodes Discord Snowflakes with Get User public fields, and runs RDAP, DNS and IP lookups.
  • What MyRecon does not do: it cannot bypass login walls or private settings, retrieve home addresses, phone numbers or private messages from a username or Discord ID, guarantee that two matching handles belong to the same person, or prove that an identifier has never been breached.

6. Inspect published evidence and its limits

The homepage includes a recorded username comparison with captured evidence and uncertainty, and our 27 November 2026 WhatsMyName 690-rule replay publishes raw rule-level outcomes. Small samples do not establish general accuracy across every niche platform.

The source code is available in the official GitHub repository; published source alone does not prove the deployed build or third-party behavior. You can report any false positive or reproducible bug through Contact.
