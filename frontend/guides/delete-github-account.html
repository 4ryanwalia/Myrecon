How to Delete a GitHub Account, and What Stays Public After

Published 25 November 2026 · 9 min read

Deleting a GitHub account takes about a minute. Working out what that minute removes takes longer. The account's own repositories, wikis, issues and Pages sites go, but your username becomes free for someone else after 90 days, some repository names are retired forever, and the commits you pushed to other people's projects are not yours to delete. This guide walks through GitHub's own steps, quotes what GitHub says happens next, and covers the checks worth doing before you press the button.

The short answer

Yes, you can delete your own GitHub account: Settings → Account → Delete your account, then type your username or email and a confirmation phrase. GitHub says that once the account is deleted it "cannot restore your content", and that your username "will be available for anyone to use after 90 days".

Steps and quotes are from GitHub Docs, "Deleting your personal account" and "Personal account reference", read 25 November 2026. GitHub changes its settings pages from time to time, so the labels may move.

Before you delete: five checks

  1. Back up what you own. GitHub asks you to make a copy of "all repositories, private forks, wikis, issues, and pull requests owned by your account" first. A git clone of each repository keeps the code and history; issues and pull requests are not part of a clone, so export anything you need from them separately.
  2. Sort out your organizations. If you are the only owner of an organization, GitHub requires you to transfer ownership to someone else or delete the organization. If there are other owners, you must remove yourself from it.
  3. Find who depends on you. Packages and container images stored in GitHub Packages under your account are deleted with it, and GitHub warns this "may break projects that depend on these packages and images". If people install anything from your account, tell them first.
  4. Cancel or move paid things. GitHub says billing "will end immediately" when the account is deleted. Make sure nothing you or a team still needs is tied to that billing.
  5. List where else the username appears. Your GitHub link is probably on a CV, a personal site, a package registry or old posts. After deletion those links point at an empty name, and after 90 days possibly at a stranger. Run the username through a reverse username lookup to see where else you use it.

How to delete your GitHub account, step by step

These are GitHub's documented steps for a personal account on GitHub.com.

  1. In the upper-right corner of any page, click your profile picture, then Settings.
  2. In the left sidebar, click Account.
  3. At the bottom of the page, under "Delete account", click Delete your account.
  4. In the "Make sure you want to do this" dialog, type your username or email in the first field.
  5. Type the phrase shown in the prompt in the second field, then confirm.

If your account is flagged, suspended or otherwise restricted, GitHub says the delete option "may be unavailable, disabled, or direct you to GitHub Support". Support will restore access to the normal flow, but GitHub is explicit that "GitHub Support does not delete your personal account on your behalf": you still finish the steps yourself.

What deleting a GitHub account removes

GitHub's reference page lists the side effects. In plain terms:

What happens to each part of a GitHub account when it is deleted, according to GitHub Docs.
Part of the accountWhat GitHub says happens
Repositories owned by the accountDeleted, along with forks of private repositories, wikis, issues, pull requests and GitHub Pages sites owned by the account
Your usernameAvailable for anyone to register after 90 days
Popular repository namesThe OWNER/REPOSITORY-NAME combination is permanently retired if the public repository had an action listed on GitHub Marketplace, or more than 100 clones or more than 100 GitHub Actions uses in the week before deletion
GitHub PackagesPackages and container images are deleted; names of public container images with more than 5,000 downloads are permanently retired
BillingEnds immediately
OrganizationsYou must transfer or delete any organization you solely own, or leave ones with other owners, before deleting

The retired-name rules exist so that nobody can register a deleted account's name and publish something malicious under a repository or image name that other projects still install from. They protect people who depend on your code. They do not stop someone from taking your plain username after 90 days.

What stays public after you delete

Deletion covers content owned by your account. Several things are outside that:

  • Commits in other people's repositories. If you contributed to someone else's project, your commits are part of that project's history. Deleting your account does not delete their repository.
  • The email address in old commits. Git records an author name and email inside every commit. GitHub notes that when you change your commit email, commits you made before the change "are still associated with your previous email address". The same is true of commits already pushed to other projects: the email in them stays as it was written.
  • Copies other people already made. Anyone who cloned a public repository has a full copy on their own machine. GitHub cannot reach those.
  • Search engines and archives. Cached copies of your profile or repositories can outlive the account for a while. Our guide to removing personal information from search results covers asking for outdated pages to be refreshed.

What happens to your GitHub username

GitHub releases the name 90 days after deletion. After that, anyone can sign up with it. This matters more than people expect:

  • Links to github.com/yourname on an old CV, a conference page or a package's metadata will lead to whoever registers the name next.
  • Someone who wants to impersonate you, or pick up trust you built, can register it and set up a profile that looks like yours.
  • A username search run a year later may show a GitHub account under your old name that is not you. When checking accounts, treat the creation date and the activity as the evidence, not the name. See how to verify that two accounts belong to the same person.

If you want to keep the name out of other hands, consider keeping the account but emptying it instead of deleting it. That is the main reason to choose one of the alternatives below.

Alternatives to deleting

GitHub's account reference describes three ways to retire a personal account: delete it, convert it into an organization, or merge it into another account. It does not describe a temporary deactivation. If you only want to step away, the options are:

Keep the account, make things private

Set repositories to private or delete the ones you do not need, clear your profile bio, picture and links, and remove the email addresses you do not want shown. The account keeps the username, and you can come back to it.

Convert it to an organization

This keeps the repositories under the same name but turns the account into an organization that other people manage. GitHub lists what you give up: you can no longer sign in to the converted account, an organization "cannot be converted back to a user", SSH keys and OAuth tokens are not transferred, installed GitHub Apps are uninstalled, commits and comments remain but are no longer linked to the account, and forks of private repositories are deleted.

Merge it into another account

Useful if you have a work and a personal account and want one. GitHub warns that access permissions do not transfer, issues and pull requests will not be attributed to the account you keep, achievements cannot move, and commits made with a GitHub-provided noreply address "cannot be transferred from one account to another".

Deleted a repository by mistake?

A single deleted repository is different from a deleted account. GitHub says a deleted repository "can be restored within 90 days", unless it was part of a fork network that still has other repositories in it. It can take up to an hour before a deleted repository shows up for restoring. For a personal account, go to Settings → Repositories → Deleted repositories and click Restore. Team permissions are not restored.

There is no equivalent for a whole account: GitHub's warning that it "cannot restore your content" after account deletion has no 90-day window attached.

Cleaning up more than GitHub

A GitHub account is often one of many old developer accounts: package registries, Stack Overflow, old CI services, forums. Search every username you have used, close the accounts you no longer want, and change any password you reused. The guide to finding and deleting old accounts sets out the order to do it in, and deactivate vs delete explains the difference on platforms that offer both.

Common questions

Can I delete my GitHub account myself?

Yes. Go to Settings, then Account, then Delete your account, and confirm by typing your username or email and the phrase shown. If the account is restricted, GitHub Support can restore access to the normal deletion flow, but it does not delete accounts on your behalf.

Can a deleted GitHub account be recovered?

No. GitHub says that once a personal account has been deleted it cannot restore your content. Back up repositories, private forks, wikis, issues and pull requests first. Single deleted repositories are different and can usually be restored within 90 days.

What happens to my GitHub username after I delete my account?

GitHub makes it available for anyone to register after 90 days. Links to your old profile will then point to whoever takes the name. Some popular repository and container image names are retired permanently instead.

Do my commits disappear from other projects when I delete my account?

No. Deletion removes content owned by your account. Commits you pushed to other people's repositories stay in their history, including the author name and email address recorded in those commits.
