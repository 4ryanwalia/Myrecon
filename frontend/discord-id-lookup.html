Discord ID lookup: decode any user, server or message ID

Paste a Discord ID, a mention such as <@175928847299117063>, or a message link. You get the exact creation date, the account age and timestamp codes you can paste into Discord. It runs in your browser; nothing is sent to MyRecon or Discord.

Compare with a second ID (spot a newer copycat account)

Try Discord's own documented example, 175928847299117063. It decodes to 30 April 2016, 11:18:25.796 UTC.

What a Discord ID lookup shows

  • Creation date and time. Exact to the millisecond, in UTC and in your own time zone.
  • Account age. How many years, months and days ago the account, server, channel or message was created.
  • Timestamp codes. All nine <t:unix:style> formats, ready to copy into a Discord message.
  • Default avatar. Which of Discord's six default avatars a user on the new username system gets if they have not uploaded a picture.
  • Which of two accounts is older. Paste a second ID to compare, which is the quickest check against an impersonator.

It does not show the current username, a custom avatar, the email address, phone number, IP address or location. None of those are stored in the ID. Sites that show a name and picture for an ID get them by asking Discord's API with a bot account; anything beyond that from an ID alone is not real.

What you can paste

The lookup reads the ID out of the common forms people copy from Discord:

  • A bare ID, 17 to 20 digits for anything created in recent years.
  • A user mention, <@ID>, or the older <@!ID> form.
  • A role <@&ID>, channel <#ID> or custom emoji <:name:ID>.
  • A message link, discord.com/channels/server/channel/message. The server, channel and message are decoded separately.
  • A profile link, discord.com/users/ID.

To copy an ID inside Discord, switch on Developer Mode in the app's Advanced settings, then use Copy User ID, Copy Server ID or Copy Message Link from the right-click or long-press menu. The Discord ID creation date guide walks through the menus on desktop and mobile.

How the date is worked out

Discord IDs are 64-bit "snowflakes". Discord's developer reference documents the layout: bits 63 to 22 hold milliseconds since the Discord epoch, 1420070400000 (the first second of 2015), and the low 22 bits hold an internal worker ID, process ID and counter. The creation time is (id >> 22) + 1420070400000.

The tool does that shift with JavaScript's BigInt. Ordinary numbers in a spreadsheet or in JavaScript lose the last digits of an 18-digit integer, which is why some quick converters are off by a few seconds.

Using account age to check an impersonator

Copycat accounts take a real person's name and picture, then message their friends or community. They cannot copy the ID. Put the real account's ID in the first box and the suspicious one in the second: if the real account dates from 2019 and the other from last Tuesday, you have your answer, and the ages go straight into your report to the server's moderators or to Discord.

Age is a signal, not proof. An old account can be stolen and a new one can be genuine, for example when someone has just lost access to their old login. For a full method, see how to identify impersonation accounts and how to report impersonation.

Discord timestamp codes

Discord turns <t:UNIX:STYLE> into a date shown in each reader's own time zone. The Unix time is in seconds. Styles from Discord's message formatting reference:

Discord ID lookup questions

Can I find a Discord user by ID?

An ID tells you when the account was created and which default avatar Discord gives it. It does not contain the username, email address, phone number or IP address. Inside Discord, Developer Mode lets you copy the ID of a user you can already see, which is the reliable way to keep track of them after a name change.

How do I tell how old a Discord account is?

Copy the user ID with Developer Mode switched on and paste it into the lookup. The first 42 bits of the ID are the creation time, so the result is exact to the millisecond and the account cannot change it.

Does a Discord ID ever change?

No. Usernames, display names, server nicknames and avatars can all change, but the ID stays the same for the life of the account, server, channel or message.

Is it safe to share a Discord ID?

An ID on its own reveals only a creation date. Share it with Discord or a server moderator when you report someone, but avoid posting it publicly next to private messages or personal details.

Can this tool see deleted accounts or private servers?

It decodes the number you paste and nothing else. It cannot tell whether an account still exists, was deleted or banned, or what a private server contains.
