Email OSINT tools for checking your own address

Updated 23 November 2026 · MyRecon editorial

Start with a breach lookup if you want to check whether your own email appears in known data breaches. Use verified email alerts for ongoing monitoring. For an address on a domain you manage, a DNS check answers a separate question about how the domain receives mail.

Two DNS results that can look alike in an email lookup

We queried Google Public DNS for MX records on 23 November 2026. Both names below are reserved examples. This comparison uses DNS records, without sending a message or requesting access to an account.

example.comStatus 0, answer 0 .The name resolves and publishes a null MX record. It declares that the domain accepts no email.

Frequently asked questions

How can I check my own email exposure?

Use a breach lookup such as Have I Been Pwned, XposedOrNot or MyRecon. Review any named breaches, the dates and the data categories reported. Use verified breach notifications if you want to monitor the address after your check.

What does a no-match email check mean?

The responding provider found no match in its available records. Check whether other sources timed out or were unavailable. A completed lookup and an incomplete check support different conclusions.

Can I run MyRecon's email check without checking linked accounts?

Yes. Check linked accounts is a separate switch and is off when you open the email tool. Leave it off for a basic check. The email lookup still sends the address to providers required for the chosen checks.

What does a null MX result tell me?

A null MX record tells mail senders that the domain does not accept email. It describes the domain's current routing, so use separate evidence for any claim about a mailbox or a past breach.
